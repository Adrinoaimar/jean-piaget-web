## Seguimiento preparado en el repositorio

- `docs/seo/tracking.json`: consultas, mercado, fuentes, privacidad y línea base.
- `scripts/check-seo.py`: comprobación HTTP, sitemap, robots, canonical, indexabilidad de Cloudflare y noindex del respaldo GitHub. Solo lectura; no envía formularios ni solicitudes de indexación.
- Ejecución desde el repositorio: `python3 scripts/check-seo.py --output /ruta/informe.json`.
- Mantener exportaciones fuera de `dist`; el build excluye docs y scripts.
- Cadencia propuesta: revisión semanal manual. No se ha creado cron, automatización ni vigilancia permanente.

## Definiciones para no mezclar métricas

| Métrica | Fuente | Regla |
|---|---|---|
| Impresiones, clics, CTR y posición media | Search Console, búsqueda Web | Filtrar país Perú y separar consultas de marca/no marca; los últimos dos días pueden estar incompletos |
| Posición SERP puntual | Captura Google con ciudad/país/dispositivo y fecha | No equivale a posición media GSC ni ranking en todos los barrios |
| Páginas indexadas | URL Inspection y reporte Indexación | No inferir del número de URL enviadas |
| Visitas por página | D1 page_view o Cloudflare Web Analytics | D1 cuenta eventos de vista, no personas únicas; no sumar ambas plataformas |
| Clics WhatsApp | D1 whatsapp_click | No equivale a mensaje enviado ni consulta atendida |
| Formulario exitoso | D1 admission_success/contact_success | Se dispara tras respuesta exitosa del intake; puede faltar por privacidad, red o bloqueadores |
| Consultas recibidas | Supabase, conteo agregado | Excluir pruebas identificadas; validar calidad en Secretaría. No publicar nombres, teléfonos ni mensajes |
| Matrículas | Gestión institucional | No se deducen automáticamente de formularios ni de D1 |

El día de esta auditoría contiene visitas técnicas en los contadores sin identificador individual; no pueden descontarse con precisión. Conservarlos como datos brutos y comenzar una ventana de referencia posterior sin visitas de prueba. En futuras comprobaciones usar DNT/GPC o el entorno local/preview. No reescribir los datos brutos como si fueran tráfico comercial limpio.
